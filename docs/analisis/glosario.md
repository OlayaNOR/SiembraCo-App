# Glosario del caso

Términos que usa el equipo con un único significado en documentos, tablero y pantallas.

| Término | Definición |
|---|---|
| Siembra virtual | Cultivo que el cliente adquiere en la plataforma y que un agricultor aliado ejecuta en campo |
| Agricultor aliado | Productor registrado en SiembraCo que ejecuta los cultivos asignados |
| Finca asignada | Predio donde se materializa la siembra virtual del cliente |
| SiembraCo Plus | Plan premium con prioridad en cosecha, seguimiento ampliado y beneficios exclusivos |
| Cosecha programada | Entrega en la fecha acordada tras completar el ciclo del cultivo |
| Trazabilidad alimentaria | Capacidad de rastrear origen, manejo y condiciones del alimento desde la siembra hasta la entrega |
| Buenas Prácticas Agrícolas (BPA) | Estándares de manejo del cultivo que garantizan calidad, inocuidad y sostenibilidad |
| Normativa INVIMA | Regulación colombiana sobre seguridad alimentaria |
| Monitoreo de cultivo | Seguimiento de las etapas de siembra, crecimiento y cosecha reportadas al cliente |
| Experiencia post-siembra | Interacción del cliente con la app después de confirmada su siembra |
| Notificación push | Mensaje enviado directamente al dispositivo del usuario |
| MVP | Versión mínima funcional para validar la solución |
