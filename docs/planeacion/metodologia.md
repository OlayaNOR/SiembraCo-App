# Esquema metodológico

## Propuesta: híbrido

Iteraciones quincenales con backlog priorizado, combinadas con los artefactos de gestión formal que exige el cliente (cronograma, presupuesto, matriz de riesgos, actas).

**Prácticas que se adoptan:** iteraciones de 2 semanas, backlog priorizado, tablero visual, revisión y retrospectiva al cierre de cada iteración.

**Prácticas que no se adoptan:** los roles formales de Scrum (product owner, scrum master), porque el liderazgo ya rota por fase.
